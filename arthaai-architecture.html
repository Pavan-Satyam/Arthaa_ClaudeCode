01

Architectural Vision & Paradigm Shift

The deployment of advanced financial intelligence demands a fundamental departure from monolithic application designs and linear processing pipelines. ArthaAI operates at the intersection of quantitative finance and generative AI, processing heterogeneous datasets — from high-velocity market tick data to unstructured geopolitical sentiment and satellite-derived alternative intelligence.

The core philosophy relies on a highly decoupled, multi-agent Large Language Model framework. Single-agent systems, while simpler to build, rapidly suffer from context degradation, catastrophic forgetting, and unmanageable prompt complexity at scale. To resolve the unpredictability of probabilistic LLMs inside a deterministic financial environment, ArthaAI isolates reasoning into specialised sub-agents, orchestrated by a macro-level directed graph that maintains a unified global state.

Because autonomous agents with financial-data access and external API execution represent an unprecedented expansion of the attack surface, the entire ecosystem is bounded by a strict zero-trust security paradigm: cryptographic identity attribution for every action, authorization enforced at the database layer, secrets held in secure vaults, and resilience against external failures through circuit-breaker topologies. Finally, the platform articulates why a prediction was made before an Asset Manager module determines capital allocation using risk-constrained continuous compounding.

03

Multi-Agent Orchestration & Control Flow

ArthaAI layers macro-level workflow orchestration with micro-level reasoning execution. At the top, LangGraph is the foundational orchestrator for directional and recursive processes, decomposing complex queries into discrete analytical steps. Rather than a single context window, it uses a GraphState primitive — a shared-state mechanism every node can access, append to, and reference. This is critical for financial analysis, which is nonlinear and iterative: a sentiment reading may loop back to the historical database for correlation testing, natively supported by LangGraph's cyclic graph structure.

One level beneath, individual nodes use Strands Agents to manage granular interactions between foundation models and tools. When a task routes to a node, the Strands agent reasons on the sub-query, triggers specialised tools to retrieve metrics, and synthesises a structured response for the global state — separating macro-workflow management from micro-execution.

The integration bottleneck is solved with the Model Context Protocol (MCP) — an open standardisation layer acting as a universal interface for AI applications. Standardised MCP servers for internal databases and external vendors let agents dynamically discover and connect to sources without hardcoded, fragile API modifications, reducing integration complexity exponentially.

05

Master Reasoning LLM — the "Brain"

At the apex of Tier 2 sits an aggregator model built for complex logical deduction. Once worker agents populate the LangGraph State Store with quantitative arrays, sentiment vectors, and physical data, the Master Reasoning LLM ingests this unified context. Its directive is to evaluate conflicting signals — a bullish technical breakout contradicting bearish satellite inventory congestion — and synthesise a probabilistically weighted forecast.

Crucially, the model is mandated to produce an explicit, step-by-step reasoning chain, concluding with "I choose this because of that reason." This transforms the system from a black-box oracle into an explainable, auditable platform that human oversight committees can trust.

SEAL

Self-Adapting Language Models generate synthetic training data and self-edits in offline staging to continuously improve financial logic via few-shot learning.

Replay Buffers

Catastrophic-forgetting mitigation: memory replay and constrained gradient updates preserve knowledge of historical anomalies (2008, 2020).

NeMo Guardrails

Programmable input, output, and execution rails intercept the logic flow; hardcoded circuit breakers enforce drawdown limits and mandatory stop-losses.

Evals

Offline backtests audit for look-ahead bias; online evaluations monitor decision trajectories and reasoning traces in real time.

06

Zero-Trust Security, Identity & Governance

Perimeter-based security — which trusts a token once it crosses the network boundary — is fundamentally insufficient for dynamic AI. If a single agent is manipulated via prompt injection from a scraped article, a perimeter model lets it pivot laterally. ArthaAI assumes breach is constant: nothing is trusted by default; every action is cryptographically verified, explicitly limited, and comprehensively logged, under the CSA Agentic Trust Framework.

ArthaAI shifts the trust boundary to the database engine: agent operations execute within sessions scoped to the current user's permissions, so even a manipulated query is rejected at the source.

Data Persistence & Retrieval

Financial architecture requires a bifurcated data strategy: a specialised time-series store for quantitative metrics and a performant vector store for narrative intelligence. For time-series, ArthaAI implements TimescaleDB — a production-grade extension for PostgreSQL — over alternatives, keeping full SQL-ecosystem compatibility while adding time-based indexing and chunk pruning.

Time-series database evaluation
SolutionQuery languageArchitecturePrimary advantage
MongoDBMQL (BSON)General-purpose document storeRapid schema iteration, but inefficient for dense time-series math.
InfluxDBFluxPurpose-built time-seriesAggressive columnar compression, but proprietary query syntax.
TimescaleDBSQL (PostgreSQL)Relational time-seriesStandard SQL extended with time-based indexing and chunk pruning. Selected.

The schema pairs relational tables (e.g. crypto_assets metadata) with hypertables (e.g. crypto_ticks) that auto-partition into 7-day chunks, storing time as TIMESTAMPTZ for UTC normalisation. Specialised functions like time_bucket plus continuous materialised views offload OHLCV aggregation from the agents.

For narrative intelligence, ArthaAI uses Qdrant — an open-source vector engine in Rust — alongside Tensorlake pipelines that parse complex financial PDFs and enrich every chunk with document-level metadata. Payload indexing attaches structured metadata (tickers, timestamps, authority scores) to vectors so the News_Agent applies hybrid search: hard metadata filters narrow scope before semantic similarity runs, eliminating cross-asset contamination. A Kafka event bus decouples data producers from consumers so ingestion spikes never bottleneck the analytical agents.

08

Microservices Resiliency

In a decoupled environment, a single unresponsive vendor can tie up agent threads, exhaust memory, and cascade into total downtime. Built on FastAPI, the platform enforces connection pooling, request batching, and token-bucket rate limiting (slowapi). Its cornerstone is the Circuit Breaker pattern (pybreaker), integrated into FastAPI middleware to enforce fail-fast isolation across three states.

CLOSED

Default healthy state. Requests flow freely to the external service; the breaker keeps a rolling window count of failures.

OPEN

Failure rate exceeds threshold (e.g. 5 timeouts / 10s). The circuit trips — subsequent requests are rejected immediately without a network call, preventing resource exhaustion.

HALF-OPEN

After a timeout elapses, a strictly limited set of probe requests test recovery. Success resets to CLOSED; failure reverts to OPEN.

When a breaker opens or retries are exhausted, the system degrades gracefully to predefined fallback protocols — for example, redirecting from the primary reasoning LLM to an internally hosted open-weight model for uninterrupted, if degraded, execution.

09

Mathematical Capital Allocation

A high-probability signal is only half the challenge; realising it requires rigorous position sizing. The dedicated Asset Manager Agent translates the Master LLM's probability forecasts into precise fractional bet sizes, founded on the Kelly Criterion (1956), which maximises the expected logarithmic growth rate of capital.

Discrete Kelly · binary win/loss
f = W − (1 − W) / R

f optimal fraction of portfolio  ·  W probability of a winning trade (from the LLM's confidence interval)  ·  R historical win/loss ratio (avg positive return ÷ |avg negative return|).

Continuous Kelly · equities & futures
f* = (μ − r) / σ2

f* optimal leverage / portfolio fraction  ·  μ expected strategy return  ·  r risk-free rate  ·  σ² historical variance, fetched from TimescaleDB aggregations.

Full Kelly is notoriously dangerous — it assumes perfect knowledge of distributions, while real markets exhibit non-stationary volatility and fat tails. Following Busseti et al. (2016), the agent enforces a risk-constrained optimisation that treats maximum drawdown as a hard constraint, then applies a fractional multiplier (half- or quarter-Kelly) for a smoother equity curve. Across a multi-asset universe, individual fractions summing above 1.0 are scaled proportionally downward.

Deterministic override

If the risk-constrained Kelly calculation suggests risking 15% of capital on a single crude-oil position but policy caps single-instrument exposure at 5%, the deterministic policy parameter permanently overrides the probabilistic model — AI remains bound by the mathematical reality of risk management.

Incremental Deployment Roadmap

A big-bang deployment of a zero-trust multi-agent system invites massive integration failure. ArthaAI is deployed incrementally as modular microservices across five sprints.

1SPRINT

Core Infrastructure & API Gateway

Kubernetes clusters, the secure GenAI API Gateway (mTLS, rate limiting), the Kafka event bus, and HashiCorp Vault integrated with the identity provider for SPIFFE/SPIRE issuance and dynamic secret injection.

2SPRINT

Database Agent & Historical RAG

TimescaleDB hypertables for tick ingestion and OHLCV aggregation; Qdrant plus Tensorlake for hybrid search and payload indexing. The DB_Agent ships as a standalone microservice, verified to pull pricing data without hallucination.

3SPRINT

Live News Agent & Sentiment

The News_Agent connects to external market APIs and providers like Permutable and LSEG, tuning embeddings and enforcing Qdrant payload filters so sentiment is attributed to the correct asset.

4SPRINT

Master LLM Orchestration

LangGraph as the macro-orchestration engine with GraphState schemas and routing nodes; standardised MCP servers; the Master Reasoning LLM introduced behind human-in-the-loop checkpoints requiring manual approval of its synthesis.

5SPRINT

Execution Engine & Hardening

The Alt_Agent ingests satellite intelligence; the Asset Manager Agent activates Kelly-optimised allocation; OPA sidecars enforce Rego on every execution graph; OpenTelemetry pipelines track prompt-to-tool chains against semantic drift and exfiltration.
